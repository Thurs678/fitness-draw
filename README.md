# FIT//DRAW — 黑客终端风健身抽签器

一个单文件、零依赖、免联网的健身动作抽签工具，界面模拟老式 CRT 终端。

在线体验：见仓库 Pages 地址或自定义域名。

## 特点

- **单文件**：整个应用就是一个 `index.html`，双击浏览器即可运行
- **零依赖**：不需要 Node、不需要构建、不加载任何外部资源
- **无音效**：完全不使用音频，静音环境可用
- **全按钮操作**：无需输入任何命令，零基础也能用
- **数据本地化**：抽签历史存在浏览器 `localStorage`，不上传任何数据

## 功能

| 功能 | 说明 |
| --- | --- |
| 开机序列 | 逐行打印 BIOS 启动日志，点击可跳过 |
| 抽签 | 单抽或一次抽 1–5 个不重复动作，带乱码滚动与锁定高亮动画 |
| 肌群筛选 | 全部 / 胸 / 背 / 腿 / 肩 / 手臂 / 核心 |
| 动作库 | 内置 32 个动作，含器械、难度、组数次数与休息建议 |
| 防重复 | 最近 10 次抽到的动作不再出现，池子耗尽时自动重置并提示 |
| 休息计时器 | 30 / 45 / 60 / 90 秒预设，ASCII 进度条，可暂停、继续、归零 |
| 历史记录 | 查看最近抽签记录，可一键清空 |

## 本地运行

直接用浏览器打开 `index.html` 即可。

如需通过本地服务器访问：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 部署

本站通过 GitHub Pages 托管，`main` 分支根目录即发布源。

`CNAME` 文件用于绑定自定义域名。

## 目录结构

```text
.
├── index.html     # 全部代码（HTML + CSS + JS）
├── CNAME          # GitHub Pages 自定义域名
├── .nojekyll      # 跳过 Jekyll 处理，保证静态文件原样发布
└── README.md
```
